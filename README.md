# Portfólio · Zullaê Ramires

Site pessoal com meus projetos, experiências e contato.
Feito em HTML, CSS e JavaScript, sem frameworks.

**No ar:** https://zulla-ramos.github.io

## Como editar

- Projetos e experiências: `dados.js`
- Textos fixos (sobre, habilidades, contato): `index.html`
- Visual: `styles.css`
- Imagens e vídeos: pasta `midia/`

Depois de alterar `styles.css`, `dados.js` ou `script.js`, aumente o número `?v=` no `index.html`. Assim o navegador de quem visita baixa a versão nova.
